# Target Matrix

40 subtypes across 5 archetypes (Grasses, Trees, Shrubs, Succulents, Forbs) in 16 niches (4 terrains × 4 climates).

## How to Read This

Each niche has two constraints:

- **Excluded** (hard): Subtypes that must NOT appear in the top-5. These are the "obviously broken" cases — palms in a German forest, cacti in a swamp. Violations here look wrong to a human.
- **Strong archetypes** (soft): Which archetypes should have at least one subtype performing well. A temperate forest should have trees, a desert should have succulents. Which *specific* subtype within each archetype wins is left to evolution.

Everything not excluded is allowed. A subtype not listed as excluded can appear freely — even if it's surprising, that's evolution finding unexpected strategies, which is a feature.

- **Strong**: Trees, Shrubs, Forbs
